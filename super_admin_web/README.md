# ClinResearch Super Admin Institutional Governance Portal

A dedicated, desktop-class web application for institutional research deans, ethics committee chairs, and compliance administrators.

---

## 🏛️ Governance Capabilities
1. **Executive Overview Dashboard**: Real-time census of institutional studies across all 8 stages, active specialists, and compliance metrics.
2. **Specialist Vetting & Accreditation**: Review doctor medical registrations (MCI, NPI, GMC), approve mentors, and issue verified badges.
3. **Protocol & IEC Oversight**: Inspect study dossiers, mentor sign-offs, and Grade-6 readability informed consent sheets.
4. **Automated PHI / PII Privacy Sentinel**: Zero-trust compliance monitor tracking prompt-level de-identification.
5. **Cryptographic Audit Trail**: Immutable event logging with single-click JSON export.

---

## 🚀 How to Run the Web Application
Simply open `index.html` in any web browser:
```bash
# Option 1: Direct file launch
start super_admin_web/index.html

# Option 2: Local HTTP Server (Python)
python -m http.server 3000 --directory super_admin_web
# Then open: http://localhost:3000
```
